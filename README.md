# sky-take-out-rebuild
项目代码完整代码在after分支，这个是main分支。
面向校园场景的综合生活服务平台，包含外卖点餐与社区论坛两大子系统。外卖系统覆盖 C 端浏览点餐 → 微信支付 → 骑手配送 → 订单完成的全业务链路；论坛系统提供发帖、回帖、关注、点赞、举报、敏感词过滤等社区功能。搭配 Vue 2 + Element UI 管理后台与 uni-app 微信小程序，Nginx 统一反向代理。项目重点实践了企业级性能调优、多角色安全认证与代码质量治理。这个项目是与舍友一起写的，是我写的第一个项目为网络上的苍穹外卖，跟着敲的代码，这个项目对这个苍穹外卖进行了重构，添加了一些其他功能并且进行优化。
