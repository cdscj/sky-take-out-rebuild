# 文心论坛

#### 介绍
文心论坛是一套简单易扩展的论坛平台，页面风格简洁自由，有别于传统的古板风格，可以作为互联网上独立的交流互动平台，也可以作为企业官网、各类业务平台的补充。

平台提供Web端、移动端和后台运营管理端三部分，其中核心Web端完全开源。

#### 技术选型

• 前端采用Vue、Element UI。

• 后端采用Spring Boot、Spring Security、Redis & Jwt。

• 本平台后台基于若依分离版本开发，特别感谢：[Ruoyi](https://www.ruoyi.vip/)。


#### Web端内置功能

1. 用户登录注册功能。
2. 用户发帖功能。
3. 用户答复功能。
4. 用户关注、点赞、举报功能。
5. 主题标签功能。
6. 个人中心功能。
7. 其他论坛常用的功能。
